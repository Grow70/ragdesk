# 演示数据｜模拟企业资料清单与验收场景

本目录中的八份资料均为专门编写的虚构内容，不对应真实企业、员工或内部制度。`a/` 与 `b/` 是逻辑知识库 A、B 的资料分组；[manifest.json](manifest.json) 逐项记录稳定的**样例文档标识**、标题、归属和原始文件字节的 SHA-256。样例文档标识用于追踪语料；未来上传到数据库后产生的 `documents.id` 是另一种 ID。文件均为 UTF-8 文本，本文和清单不作为待上传资料。

## 综合不同文档的问题

以下问题供以后构建检索与引用验收集使用；本步尚未运行检索或问答。文档正文保留制度与说明文体，没有写成问答对。

1. **只选 A 库：**“普通城市客户现场出差已按期获批，住宿每间夜 650 元，行程单和电子发票齐全，但结束后第 16 个自然日才提交；没有平台故障工单，能否报销？”应同时依据 A-TRV-002 的审批效力与 A-EXP-001 的住宿、材料和提交期限判断：审批与金额条件不能豁免逾期。
2. **只选 A 库：**“NX-210-P 批量同步一批 400 条记录时，同一租户一分钟发出 70 次请求并收到 HTTP 429；这是否已达到 P1？”应结合 A-PRD-004 的版本和单批能力、A-API-005 的每分钟 60 次限流及 429 分类、A-OPS-006 的连续 5 分钟超过 2% 的 5xx 门槛判断。仅有 429 不足以判定 P1；是否另有 5xx 证据需进一步确认。

## 跨库隔离对照

- 只选 A 库问“普通城市住宿每间夜 600 元、出差结束后第 12 个自然日提交，本库审批和电子发票齐全且没有特批，是否满足金额和期限条件？”：A-EXP-001 的金额与期限均允许。只选 B 库问同一条件：B-EXP-001 的 520 元上限不允许无特批报销超额部分；不能引用 A-EXP-001。
- 只选 A 库问“NX-210-P 的 5xx 错误率为 2.5%，持续 6 分钟，是否满足 P1 数值门槛？”：A-OPS-006 满足。只选 B 库问同一条件：B-OPS-002 尚未达到 3% 且连续 10 分钟的门槛；不能引用 A-OPS-006。

这些对照只检查资料设计是否具备可区分事实；实际检索隔离、权限、引用和回答效果须在后续对应步骤单独验证。
