# 演示数据｜A 库运维事件流程

文档标识：A-OPS-006  
知识库：A（星桥演示集团）

## 事件分级

NX-210-P 生产接口的 HTTP 5xx 错误率连续 5 分钟高于 2% 时，值班人将事件定为 P1。分母为同一时段的全部生产 API 请求，分子仅为 5xx；HTTP 429 是 4xx，不计入分子。单个客户的 429 激增应先核对接口限流规则，不凭该现象直接宣告 P1。

## 响应步骤

值班人在收到 P1 告警后 10 分钟内确认（ACK），记录事件编号和影响范围；首次对外状态更新须在确认后 30 分钟内发出。若新版本发布后达到上述阈值，负责人评估回滚，并在变更记录中写明决策；不能把回滚当作无须通告的静默操作。

## 计划维护例外

有事先批准的维护单且已提前通知客户时，维护窗口内的预期 503 先按维护单处置；若 5xx 持续到窗口结束后仍高于阈值，则转入 P1。此例外不改变 429 与 5xx 的分类。
