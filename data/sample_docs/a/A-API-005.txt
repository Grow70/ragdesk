演示数据｜A 库 NX-210 接口错误码
文档标识：A-API-005
知识库：A（星桥演示集团）

一、适用范围
以下错误码适用于 NX-210-P 批量同步 API。单批最多 500 条记录的产品限制另见《NX-210 产品能力说明》（A-PRD-004）。HTTP 状态码与业务错误码应同时记录。

二、请求频率与权限
同一租户超过每分钟 60 次批量同步请求时，接口返回 HTTP 429 / RATE_LIMIT，并在 Retry-After 响应头给出建议等待秒数。缺少 sync:write 范围时返回 HTTP 403 / SCOPE_DENIED；拥有 SSO 登录权限不自动获得此范围。

三、参数与版本冲突
单批超过 500 条或必填字段缺失时返回 HTTP 422 / FIELD_INVALID。并发修改同一批次版本号时返回 HTTP 409 / REVISION_CONFLICT；这与 429 的请求频率限制不同，不能仅靠延长等待时间解决。

四、故障判别
HTTP 429 属于 4xx 限流响应，不计入《A 库运维事件流程》（A-OPS-006）的 5xx 错误率。若接口返回 HTTP 503 / SERVICE_UNAVAILABLE，才属于该流程统计的 5xx；计划维护期间的处理仍需查看运维流程中的例外条款。
