# 演示数据｜NX-210 产品能力说明

文档标识：A-PRD-004  
知识库：A（星桥演示集团）

## 产品与版本

NX-210 是虚构的客户资料同步产品。NX-210-B 为基础版，支持手动导入 CSV；NX-210-P 为专业版，除手动导入外，还支持通过 API 发起批量同步。两个版本都支持单点登录（SSO），但 SSO 权限不等于批量同步 API 权限。

## 批量同步条件

NX-210-P 的批量同步须使用具有 `sync:write` 范围的令牌，每批最多 500 条记录。超过单批数量会被参数校验拒绝；请求频率限制与错误码见《A 库 NX-210 接口错误码》（A-API-005）。

## 数据可见性

同步完成后，产品控制台显示已处理记录数；“已接收”不表示全部记录同步成功。若返回失败条数，操作者须查看批次结果，再按失败原因处理，不应把重试视为已成功。
